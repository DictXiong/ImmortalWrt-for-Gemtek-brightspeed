XR1710G Full 现在提供 `gateway` 与 `ap` 两种默认角色，驱动、软件包和 wrtix 完全相同，仅初始网络配置不同。Fixes 通用修复版停止维护和新增构建，历史发布保留。

3.1.0-rc.1 集成以下更新。

- Airoha PPE 桥接修复，校验同口 hairpin 与桥端口状态，补齐 FDB 删除／移动及端口事件的撤销。动态 FDB 老化前查询硬件源地址活动，同端口 ADD 保留有效绑定。
- wrtix 更新到独立项目的 1.1.0-rc.1，包含配置导入、部署准备与事务管理改进。
- 独立 wrtmesh 6.2.0 包提供节点发现、邻居同步、站点和拓扑视图。概览页通过软件包自带的 LuCI 扩展显示拓扑与按接入节点分组的对端无线客户端。

继续包含 EIP93 硬件加密及 AES 软件回退依赖。实际功能验收与未覆盖项以本次 Release 的测试记录为准。

- **`gateway` 网关模式**：WAN 获取 DHCP 地址，LAN `192.168.1.1` 提供 DHCP／NAT。
- **`ap` 接入点模式**：四个网口全部桥接，自身从上游获取 DHCP 地址，不提供 DHCP／RA 服务。接入可信上游后，通过网关租约表查找管理地址。

两种角色均包含硬件／驱动修复、改进的 WebUI、zsh／Vim／tmux、可选的 wrtix 与有线回程漫游。无线和漫游初始关闭；用户名 `root`、密码为空，SSH 为 LAN 侧端口 22。首次使用请设置认证并配置网络。镜像不含个人凭据、热点、维护地址或正式 MAC 规划。

默认角色在清空配置或恢复出厂时生效；保留配置升级不会切换现有网络。AP 镜像离线直连时需要另行准备管理通路，不提供初始 DHCP 服务。wrtix 配置管理仍为可选功能。

选择匹配现有分区布局的角色镜像，核对附件 `sha256sums` 并备份配置后升级。升级不转换分区，也不更新 U-Boot、Recovery 或原厂校准数据。附件提供每种角色的 ITB、配套 APK、精确源码与来源记录；不同构建的软件包尤其是 kmod 不可混用。

构建与角色检查以本次 Release 的验收结果为准；不能将既有网关镜像或保留配置升级的结果作为新 AP 默认配置的实机验证。部分客户端的漫游及 Wi-Fi 7 兼容性限制仍需按对应测试记录评估。
