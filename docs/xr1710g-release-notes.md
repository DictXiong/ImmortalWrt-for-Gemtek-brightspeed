XR1710G 3.0.0 同步 naoki 上游，提供完整版与通用修复版；完整版集成正式版 wrtix 1.0.0。

- **`full` 完整版**：通用硬件/驱动修复、改进的无线/MLO WebUI、zsh/Vim/tmux、可选的声明式配置管理与有线回程漫游。可直接作为普通 OpenWrt 使用，无需 Nix。
- **`fixes` 通用修复版**：固定 naoki 基线与通用硬件/驱动修复，保留该基线的软件包和默认行为。两版均包含 MT7996 Beacon Protection 能力声明。

`full` 初始 LAN 为 `192.168.1.1` 并提供 DHCP，WAN 使用 DHCP/NAT；无线和漫游默认关闭。用户名 `root`、密码为空，SSH 为 LAN 端口 22；首次使用请设置密码并配置网络。固件不含个人公钥、密码或 AP 策略。wrtix 采用新的通用资源协议，旧版内置 AP 配置文件需改用匹配的 wrtix 配置；它仍是可选功能。

下载匹配现有分区布局的 `.itb`，核对 `sha256sums`，备份后通过系统升级页面刷写。首次跨版本切换建议不保留配置；受 wrtix 管理的设备按其升级文档保留已声明配置。升级不转换分区，也不更新 U-Boot、Recovery 或原厂校准数据。附件包含两版各自的 APK、精确源码和构建记录；不同构建的软件包尤其是 kmod 不可混用。

已验证四热点基础连接、WPA2/WPA3、双栈联网、访客 VLAN 隔离、PPE 绑定及源地址伪造/VLAN 注入防护；另测通过 6GHz 与 5+6GHz MLO 基础连接。约七小时连续观测未发现 WAN 闪断或内核异常，出现少量 IPv6 时延/丢包告警；控制器重启中断了原定八小时测试。正式版只调整发布版本、wrtix 版本标识和文档，功能代码沿用该候选。

已知限制：部分客户端受控漫游仍有数秒中断，个别 WPA2 场景超过五秒；部分 Wi-Fi 7 客户端存在 Beacon Protection/组播兼容性问题。未验证所有客户端、自然漫游、Beacon 空口完整性或八小时 MLO 稳定性。
