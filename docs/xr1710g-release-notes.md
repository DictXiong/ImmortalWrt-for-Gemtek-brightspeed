XR1710G 3.0.0-alpha.1 是完整功能版的首个预发布，将固件功能与个人配置分离。

- **`full` 完整版**：通用硬件/驱动修复、改进的 WebUI、zsh/Vim/tmux 离线终端环境、可选的 `wrtix-agent` 配置管理与 `xr-roaming`。可直接作为普通 OpenWrt 使用，无需 Nix。
- **`fixes` 通用修复版**：固定 naoki 上游快照与通用硬件/驱动修复，保留该基线的软件包和默认行为。

`full` 默认 LAN 为 `192.168.1.1` 并提供 DHCP，WAN 使用 DHCP/NAT；无线和漫游关闭。不预置个人公钥、共享密码、维护地址或 AP 策略。初始用户名 `root`、密码为空，SSH 为 LAN 端口 22；请先从可信 LAN 设置密码，再配置网络和无线。wrtix 用户需使用与内置 agent 匹配的控制器，热点、VLAN、地址与秘密由自己的配置声明。

下载匹配现有分区布局的 `.itb` 并核对 `sha256sums`。从 `2.x custom` 切换到 `3.0 full` 时，请先备份、不保留旧配置升级，再通过 LuCI 或 wrtix 重新配置；旧运行时不提供迁移接口。本发布不转换分区、不更新 U-Boot、Recovery 或原厂校准数据。附件提供各版匹配的 APK、精确源码和构建记录；不要混用不同构建的 kmod/APK。

构建检查覆盖镜像布局、文件完整性、软件包匹配和默认配置。相关 Full 候选已取得 LAN DHCP／WAN NAT、可选 Nix 初始化与重复部署、WPA2/WPA3、本地双栈 TCP、6GHz、5＋6GHz MLO、PPE 绑定并存时的访客隔离及 WebUI 实机通过记录。受控漫游仍有超过 2 秒的中断，个别 IPv6 恢复更慢；USB 客户端也有偶发 HTTPS 超时。旧版对照存在同类现象，但未证明每项故障和发生频率均相同，根因尚未确定。短测不代表长期稳定性、全部客户端兼容性或多频同时聚合吞吐。
